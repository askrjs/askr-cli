# CLI: add

Generate feature code into an existing Askr project.

`askr add` now ships with an initial `page` generator for route-first SPA apps.
Additional generators remain on the roadmap.

## Philosophy

Generators will scaffold files according to Askr conventions. Generated code
should remain ordinary Askr code: no runtime magic and no generator dependency.

## Shipped command

```bash
askr add page <name>
askr add page <name> --branch public
askr add page ops/audit-log --cwd ./my-app
```

Options:

- `--branch app|public` chooses which route branch owns the page. Default is `app`.
- `--cwd <dir>` points the generator at an existing project directory.
- `--title <text>` overrides the generated page title.
- `--route <path>` overrides the generated route path.
- `--force` overwrites an existing page file.

Current support:

- Route-first SPA projects generated by `askr create spa`
- `src/pages/app/_routes.tsx`
- `src/pages/public/_routes.tsx`

Generated output:

- `src/pages/<branch>/<name>.tsx`
- Route registration in `src/pages/<branch>/_routes.tsx`

## Planned commands

```bash
askr add route <path>
askr add crud <model>
askr add table <name>
askr add form <name>
```

## `add page`

`add page` scaffolds a route component and registers it in the branch router.

Expected output:

- `src/pages/<branch>/<name>.tsx`
- Route registration in `src/pages/<branch>/_routes.tsx`

## `add crud`

The planned `add crud` command will scaffold list, detail, create, edit, and
delete UI for a model.

Expected output:

- `src/pages/app/<model>.tsx`
- `src/pages/app/<model>-detail.tsx`
- `src/features/<model>/<model>-table.tsx`
- `src/features/<model>/<model>-form.tsx`
